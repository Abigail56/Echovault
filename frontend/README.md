# EchoVault Nexus — frontend

Next.js (Pages Router) app. See the [root README](../README.md) for setup, architecture and testing.

```bash
npm install
npm run dev        # http://localhost:3000 (proxies /api/v1 to BACKEND_URL, default http://127.0.0.1:8000)
npm run lint && npm run typecheck && npm test && npm run build
```
